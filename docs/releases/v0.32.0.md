# DemonX Forge 0.32.0

Text in sketches, and Construction planes.

**Text** (SKETCH tab, CREATE ▾ > Text): click where the text starts, then type it in the box: the text, the font, the height of a capital letter in mm, left / centre / right, bold, italic. OK turns the letters into sketch shapes you can Extrude or Cut (engraving and raised lettering).
- **Fonts:** any font installed on the computer works, by name (Arial, Segoe UI, Impact, Consolas…). "Find the installed fonts…" lists them (Chrome and Edge ask once for permission). Leave Font empty for the built-in font (Liberation Sans). A name that is not installed is refused with a message and the box stays open. A font **file** cannot be used: only names.

**Construction planes** (SOLID tab, new CONSTRUCT group):
- **Offset Plane:** a plane parallel to an origin plane, another construction plane or a clicked flat face, a typed distance away.
- **Plane at Angle:** a plane tipped about the X, Y or Z axis by an angle.
- **Midplane:** halfway between two planes or faces.
- Each shows live while its box is open. The planes appear in the browser under **Construction** (eye to hide, right-click for Create Sketch / Rename / Delete) and in the view as amber sheets with their name. **Create Sketch** offers them next to XY, XZ and YZ, and you can click a sheet in the view.
- A short how-to is in `docs/guides/construct-planes.md`.

**Tested:** real engine and real browser (`e2e/text.mjs`: text, a missing font, a font file path; `e2e/construct.mjs`: each plane tool, a plane from a clicked face, the browser, sketching on a plane and through the picker), unit tests that compare each plane's position with where the engine itself puts a sketch on it, and the whole e2e suite. **Not tested:** Windows (the font list and the system fonts are the main thing to try there), the real Windows fonts by name, and planes that depend on a parameter expression (they are made but not drawn: their sheet needs a number).

**Not done:** Planes through three points, two edges, along a path or tangent to a round face, and axes and points (the engine has them); editing a plane's numbers from the timeline; Text editing after it is placed (delete and place again for now).
