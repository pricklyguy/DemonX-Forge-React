# DemonX Forge 0.29.0

Torus, and working with whole bodies: select, rename, export the ones you choose (one STL each if you like), and open them straight in your slicer.

- **Torus** (CREATE, next to Box, Cylinder and Sphere). Major radius, minor radius, centre; click a face to place it. It starts as a New Body, because joining a torus to another body is slow in the engine.
- **Select a whole body.** Click its name in the browser (Ctrl or Shift adds more), or double-click it in the view. The whole body lights up. Esc clears the selection.
- **Rename a body.** Double-click its name in the browser, or press F2, or right-click > Rename. Enter keeps the name, Esc leaves it. Features that use the body follow the new name.
- **Body menu** (right-click a body in the browser): Rename, Hide / Show, Isolate, Show all, Export…, Open in slicer….
- **Export the bodies you choose.** New **Export** button on the SOLID tab (INSERT group) and on the MESH tab, and File > Export bodies > "Choose bodies…". Tick the bodies, pick STL, STL text, 3MF, STEP or OBJ, and:
  - **One file per body** gives a zip of separate files named after each body (STL has no body names, so this is the way to print several parts apart).
  - **3MF** keeps each body as its own object, which slicers show as separate parts.
  - If you had bodies selected, those start ticked. The old File > Export entries still export everything.
- **Open in slicer.** On the MESH tab, **Open in Slicer** (or "Send to: A slicer" in the Export dialog) saves the chosen bodies as a 3MF or STL and opens it in an installed slicer (PrusaSlicer, Bambu Studio, OrcaSlicer, Cura and the other common ones are found on their own). The file is kept in Forge's work folder until you close Forge.
- **Safety:** the browser can now send `body.rename` to the engine, and a short list of engine commands that read or write files (DXF/SVG insert and export, text, parameter import/export, script export) is refused on the general route, since files go through Forge's checked routes. A slicer is only opened if the engine itself found it; a program path from the browser is never used.

**Tested:** real engine and real browser. `e2e/bodies.mjs` (a Torus body, selecting by row, Ctrl+click, double-click in the view, rename by double-click, F2 and right-click, Isolate and Show all, the Export dialog with a zip of two STL files and a 3MF, and Open in slicer using a stand-in slicer program), plus unit tests against the real engine: only the chosen bodies are exported (12 triangles for a box), a 3MF holds one object per body, a renamed body keeps working, and a stand-in slicer is found and started with the file. **Not tested:** a real slicer (none is installed where this was built), Windows, and what each slicer does with a 3MF that holds several bodies (PrusaSlicer, Bambu and Orca open them as separate parts; try yours).
