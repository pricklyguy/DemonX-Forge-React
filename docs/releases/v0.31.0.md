# DemonX Forge 0.31.0

Sketch Modify, Pattern, Constraint and Insert tools.

**MODIFY** (SKETCH tab; Trim, Extend, Offset and Fillet stay on the bar, the rest are in MODIFY ▾):
- **Chamfer:** click a corner where two lines meet, type the distance.
- **Break:** click a line, arc or circle where it should be split into two.
- **Move / Copy:** select curves first (click, Shift adds, or drag a box round them), then type `dx, dy` (and a turn in degrees if you want one) and choose Move or Copy.
- **Scale:** select curves, type a factor; they grow about the middle of the selection.

**PATTERN** (new group; Mirror is on the bar, the two patterns are in PATTERN ▾):
- **Mirror:** select curves, choose Mirror, click the line to mirror about (a construction line works well; X makes a line a construction line).
- **Circular Pattern:** select curves, choose it, click the point to turn about, type `count` (and a total angle if less than a full turn).
- **Rectangular Pattern:** select curves, choose it, type `count, spacing` (and `count 2, spacing 2` for a grid).

**CONSTRAINTS:** two more, **Collinear** (two lines) and **Symmetry** (two points or curves, then the line they mirror about); and an **AutoConstrain** button at the end of the grid, which adds the constraints and dimensions it can work out until the sketch is fully constrained (use it on a finished drawing, then undo if you did not want all of it).

**Insert DXF… and Insert SVG…** (in CREATE ▾) put the shapes of a file into the open sketch (a DXF from DemonX Design works). The file is read in the browser and sent as text; no path is ever sent to the engine.

**Tested:** real engine and real browser (`e2e/sketchmodify.mjs` does each of these in turn and checks the engine's result: a chamfer's area, a split line, a scaled circle, a copy, a mirrored copy, a pattern, the degrees of freedom, a DXF line and an SVG shape), unit tests for the new pick rules, and the whole e2e suite. **Not tested:** Windows; Text (needs a font file, left out on purpose for now); a real DXF from DemonX Design or a large SVG (curves in SVG paths depend on the engine's reader).

**Still to come for sketches:** Text, Project / Intersect (edges of a body into a sketch), Slot variants, 2- and 3-tangent circles, Offset on both sides, and the other constraints and dimensions.
