# DemonX Forge 0.34.0

Fixes and polish from testing 0.33.0: Text, choosing a sketch plane, and a tool-options strip.

- **Text now shows as you type.** The letters appear in the sketch a moment after you stop typing, and change as you change the text, font, height, alignment or style. Cancel takes them back; OK keeps them. The pointer is a text cursor while the Text tool is chosen (and a cross for the other drawing tools).
- **No more pile of number boxes over text.** Each short piece of a letter's outline used to get its own measured-length label. Measured labels now hide when the piece they measure is too short to read on screen (they come back as you zoom in). Dimensions you set yourself always show.
- **Choosing a sketch plane no longer fights the origin planes.** A flat face of your part is now always picked before a plane sheet, however many sheets are in front of it, and the face under the pointer lights up. If the sheets still get in the way: Preferences > "Draw the origin planes when choosing a sketch plane" off hides them; the planes then show only while the pointer is on their button in the list, and the buttons (and the browser's Origin list) still pick them.
- **Tool options strip.** While a Line, Rectangle, Circle, Arc or Polygon tool is chosen, a strip at the top of the Sketch Palette (right side) shows the other ways to draw the same thing (Rectangle: 2-point, 3-point, centre, rounded; Circle: centre, 2-point, 3-point; Arc: 3-point, centre-point; Polygon: inscribed, circumscribed, edge, with the number of sides). One click switches.
- **Midpoint Line** (new, in the Line options and CREATE ▾): click the middle, then one end; the other end is the same distance the other way. Type the whole length if you like.

**About the slicer test:** Bambu Studio says a 3MF from another program has "invalid config, load geometry data only". That message is normal for any 3MF that Bambu did not make: the geometry (and each body as its own object) loads, only Bambu's own print settings are missing. STL loaded fully, as you saw. Forge hands the file to the slicer and cannot make Windows bring the slicer's window to the front: it opens behind or beside, which is how Windows treats a program started by another.

**Tested:** real browser (`e2e/planepick.mjs`, and new checks in `e2e/text.mjs` and `e2e/sketchtools.mjs` for the preview, the cursor, the labels, the strip and the midpoint line) and the whole e2e suite. **Not tested:** Windows; the text preview with a very large font list or a slow font.

**Still open:** a "draw as construction" mode for new shapes (X toggles a selected shape today), and Line Type buttons (construction / centerline) in the strip.
