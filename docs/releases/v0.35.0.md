# DemonX Forge 0.35.0

From testing 0.34.0: the Start page at launch, a "working" message, sketch snapping to what is already there, and previous sketches you can show.

- **Forge opens on the real Start page** (the full page with Recent, New, Open on the left and Back to <design>), not the smaller panel that used to sit in an empty design. Esc or "Back to <design>" goes to the design. File > Preferences > "Show initial start options" turns it off at launch; the Home button next to the logo always opens it.
- **A message while it works.** Opening a recent design, Open, Import, loading the sample, and Update now show a centred spinner and what is happening ("Opening pc_mount.forge…", "Updating Forge: …, Forge restarts by itself"). It only appears if the job takes more than about a third of a second, so quick ones do not flash.
- **Previous sketches show again.** Forge's engine hides a sketch as soon as a feature (an Extrude, say) has used it, but the browser's eye still looked "on", so clicking it did nothing. The eye now shows the real state, and a click shows or hides the sketch for real (it is saved with the design). To see an old sketch while starting the next one, click its eye.
- **Sketches snap to what is already there.** Line, rectangle and the other drawing tools now snap (end, middle, crossing, aligned) to the straight edges of bodies that lie in the sketch's plane, and to the lines, circles and arcs of other visible sketches that do, as well as to the sketch's own shapes. This was the missing piece when starting a sketch on another body or a plane its edges did not belong to.
- **Preferences:** "Show the origin planes in the 3D view" (off at the start, as before, but now remembered) and "Show the sketch axes (red and green lines)" (on by default; the Sketch Axes tick in the palette is remembered too). Together with "Draw the origin planes when choosing a sketch plane" this lets you work with the origin out of the way.

**Tested:** real browser (`e2e/snapref.mjs`: the eye, and snapping onto a body corner that is not on the grid; `e2e/start.mjs`: launch on the Start page, the working message on a slow load; `e2e/prefs.mjs`) and the whole e2e suite. **Not tested:** Windows, the Update now message on a real update (the sandbox cannot run one; the message uses the same progress text the Updates window already showed), snapping to circular body edges (only straight edges are used: the engine does not say where a round edge's centre is).

**If I guessed wrong:** "start with the origin hidden" I took to mean the origin planes in the 3D view and the red / green sketch axes. If you meant something else (the origin point mark, say), tell me which part you see.
