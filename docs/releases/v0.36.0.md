# DemonX Forge 0.36.0

Forge can now be installed as an app: its own window and taskbar icon, no tabs and no address bar.

- **Install as an app.** In Chrome or Edge, open Forge as usual, then use File > "Install Forge as an app…" (it is also on the Start page, left column), or the install icon at the right end of the address bar. After that Forge opens from the Start menu or taskbar like any other program. The item only shows while the browser offers the install, and goes away once Forge is installed.
- **Icons and name.** The installed app is called DemonX Forge and uses the Forge icon (192 and 512 pixel versions).
- **Nothing is cached.** The small helper that makes the install possible (a "service worker") stores nothing, because your design lives in Forge's local server. An update of Forge reaches the installed app the next time it opens.
- **The server still has to be running.** The installed app is a window onto the local server (`npm start`, or the Windows package's start file). It does not start the server by itself; that is what the planned Electron version would do (see `docs/PLAN.md`).

**Tested:** real browser (`e2e/pwa.mjs`: manifest, icons, service worker, and the install items appearing and disappearing when the browser makes, or has taken, the offer). **Not tested:** the real install question of Chrome or Edge, and the installed window on Windows (headless Chromium never offers it), so please try it by hand and tell me how it feels.
