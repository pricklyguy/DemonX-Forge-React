# DemonX Forge 0.30.0

Ten more sketch tools, and a Preferences window.

**New sketch tools** (SKETCH tab, CREATE ▾ menu; the first seven stay on the bar):
- **3-Point Rectangle:** click the two ends of one edge, then a point on the opposite side to set the width (tilted rectangles).
- **Rounded Rectangle:** two corners, like the 2-Point Rectangle; the corners start at a fifth of the shorter side. Type `width, height, radius` to set the radius.
- **3-Point Circle:** three points on the circle.
- **Center Point Arc:** the centre, where the arc starts (or type the radius), then the way it ends. It runs counter-clockwise from the start.
- **Inscribed Polygon, Circumscribed Polygon, Edge Polygon:** the number of sides is in the Sketch Palette ("Polygon sides", 3 to 64). Inscribed: the radius reaches the corners; Circumscribed: it reaches the middle of the sides; Edge: click the two ends of one side, the polygon stands on the left of the way you went.
- **Ellipse:** the centre, the end of the long axis, then a point on the short side.
- **Fit Point Spline:** click the points it passes through. Enter, right-click or Esc ends it open; clicking the first point closes it.
- **Point.**
- Press, drag and release also works for the ones that take two clicks (a polygon is made by one drag).

**Preferences** (File > Preferences…): **Show initial start options**. Untick it to remove the "Nothing modelled yet" message and the demo-bracket button from an empty design. It is remembered on this computer. A proper start page (recent files, new design, samples) is on the list for later.

**Tested:** real engine and real browser (`e2e/sketchtools.mjs` draws each new tool and checks the engine's shapes by area; `e2e/prefs.mjs`), unit tests for each tool's clicks, typed sizes and previews, and the whole e2e suite. **Not tested:** Windows; the spline preview is only an approximation of the curve the engine fits (the real one is drawn once you finish); the pointer snaps to the grid, so odd sizes are typed.

Not in this release (next): Modify tools (chamfer, break, scale, move/copy, mirror, patterns), more constraints, Insert DXF / SVG, text.
