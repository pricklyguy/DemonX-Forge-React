# DemonX Forge 0.33.0

A Start page, with the designs you have saved or opened lately.

- **Start page.** An empty design now shows it in place of the old "Nothing modelled yet" note: **New design**, **Open…**, **Import…**, **Recent** and a **Samples** row (the demo bracket). The ribbon, browser and timeline stay usable beside it.
- **Home button** (the house beside the logo): opens the Start page over whatever you are working on, with a way back (**Back to <design>**, or Esc) and the file commands on the left (New, Open, Save, Save As, Preferences, Keyboard shortcuts, Updates).
- **Recent.** Every time you save or open a design it goes to the top of the list with a small picture of it and how long ago. A click opens it. In Chrome and Edge Forge keeps the file's handle, so it opens again without asking where it is (the browser asks once for permission to read it); where the browser kept no handle (a design that was only downloaded), Forge asks you to pick the file again. The ✕ removes an entry from the list (the file is not touched). The list is kept in this browser, up to 24 designs.
- **Preferences** > "Show initial start options" now controls this page: untick it for a clean empty view; the Home button still opens it.

**Tested:** real browser (`e2e/start.mjs`: the page on an empty design, loading the sample, the Home overlay and Esc, saving then finding the design in Recent with a picture, the list surviving a reload, opening from the list, removing from the list), unit tests for the list rules, and the whole e2e suite. **Not tested:** Windows, and the real Chrome / Edge file handle path (the test uses a download and the file chooser, because a scripted browser cannot answer the native Save window); the sandbox could not check that the permission prompt appears when a remembered file is opened.

**Not in yet:** design types (Part / Assembly / Hybrid; Forge has one kind of design today), New design in inches, pinning, and thumbnails for designs that were not saved from this browser.
