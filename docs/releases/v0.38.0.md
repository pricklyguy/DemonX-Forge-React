# DemonX Forge 0.38.0

New home for Forge, a newer modelling engine, and an updater that follows.

- **Forge now lives in its own repository,** `pricklyguy/DemonX-Forge-React`. The updater, the release links and the download checks now use it, so **Update** finds releases published there. Installs of 0.37.0 and older still look in the old place and will not see this release: install 0.38.0 by hand once (extract the zip over `C:\DemonX-Forge`, as in `docs/WINDOWS.md`); from then on **Update now** works as before.
- **Engine: SolidCraft 0.29.0** (was 0.19.0), built from source by the package workflow. Many sketch and constraint fixes come with it; the section DXF of a body with a hole is now complete (two closed pieces; 0.19.0 left out the side that meets the hole), and construction planes made from other planes are read by feature number as well as by name.
- Repository housekeeping: working notes and unused files removed from the public repository; `docs/DESIGN.md` replaces the planning log; README and guides refreshed.

**Tested:** all unit tests and all browser checks (`e2e/`) against a SolidCraft 0.29.0 engine built on Linux; the update checks against a fake release list. **Not tested:** the Windows build of the 0.29.0 engine (the package workflow builds it for the first time with this tag), the real update path from a published release (this repository has no release yet, so the first tag is installed by hand), and your own parts on the new engine.
